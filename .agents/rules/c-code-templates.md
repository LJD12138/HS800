# 嵌入式 C 语言文件与注释模板

## 1. 新建源文件 (.c) 模板
> **动态生成指令**：新建源文件时，必须动态识别当前工程名称（如 APP / BOOT）、当前文件实际保存目录路径以及当前系统真实日期，**严禁硬编码过往历史工程路径与旧日期**。

```c
/*******************************************************************************************************************************
 * Project : [当前工程名，如 APP]
 * Module  : [当前文件所在的相对目录路径,如APP\Hardware\Key]
 * File    : [当前文件名.c]
 * Date    : [当前真实日期，格式 YYYY-MM-DD]
 * Author  : LJD(291483914@qq.com)
 * Desc    : [文件功能描述]
 * -------------------------------------------------------
 * todo    :
 * 1. none
 * -------------------------------------------------------
 * Copyright (c) 2026 -inc
 *******************************************************************************************************************************/

//****************************************************Includes******************************************************************//
#include "xxx.h"

#if (x)
//****************************************************Macros********************************************************************//



//****************************************************Parameter Initialization**************************************************//



//****************************************************Function Declaration******************************************************//



#endif  /* x */

```

- **段落横幅**：`//` + 52 个 `*` + 标签 + 若干 `*` + `//`，**总宽 130 字符**；`.c` **只用 4 个英文标签**：`Includes`、`Macros`、`Parameter Initialization`、`Function Declaration`，**不用中文标签、不新增其它标签**（函数实现、变量/类型/参数定义分别归入 `Function Declaration`、`Parameter Initialization`）。
- **主体结束的 `#endif`**：注释写**对应条件名**（`#if (1)` → `#endif  /* 1 */`、`#if (boardADC_EN)` → `#endif  /* boardADC_EN */`），**不写文件名**。

## 2. 新建头文件 (.h) 模板
```c
/***********************************************************************************************************************
 * Project : [当前工程名，如 APP]
 * Module  : [当前文件所在的相对目录路径,如APP\Hardware\Key]
 * File    : [当前文件名.h]
 * Date    : [当前真实日期，格式 YYYY-MM-DD]
 * Author  : LJD(291483914@qq.com)
 * Desc    : [文件功能描述]
 * -------------------------------------------------------
 * todo    :
 * 1. none
 * -------------------------------------------------------
 * Copyright (c) 2026 -inc
 ************************************************************************************************************************/

#ifndef XXX_H
#define XXX_H

#ifdef __cplusplus
extern "C" {
#endif

//****************************************************Includes******************************************************************//
#include "main.h"

#if (x)
//****************************************************Macros********************************************************************//



//****************************************************Globals*******************************************************************//



//****************************************************Types*********************************************************************//



//****************************************************Extern********************************************************************//



#endif  /* x */

#ifdef __cplusplus
}
#endif

#endif  /* XXX_H */

```

- **段落横幅**：`//` + 52 个 `*` + 标签 + 若干 `*` + `//`，**总宽 130 字符**（与 `.c` 同一风格）；`.h` **只用 5 个英文标签**：`Includes`、`Macros`、`Globals`、`Types`、`Extern`（函数声明类归入 `Extern`，变量/常量类归入 `Globals`）。
- **主体结束的 `#endif`**：同 `.c`，注释写对应条件名（`#if (x)` → `#endif  /* x */`）。

## 3. 注释规范
### 3.1 函数头部注释规范
函数实现前必须添加统一注释块：
```c
/***********************************************************************************************************************
 * 函数功能    : [功能详细描述]
 * 说明(备注)  : [注意事项、调用约束或前置条件]
 * 传入参数    : [输入参数及取值范围]
 * 输出参数    : [输出指针参数说明]
 * 返回值      : [返回值含义及错误码]
 ************************************************************************************************************************/
```

### 3.2 行内注释规范
- **行尾注释**统一用 `//`（与 c-coding-style 2.2/2.3/2.4 示例一致）。
- **块注释 / 段落注释**用 `/* 中文注释内容 */`（如段落横幅、函数头注释块）。
