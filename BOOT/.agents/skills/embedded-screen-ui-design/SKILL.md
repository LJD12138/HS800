# 嵌入式屏幕 UI 设计

为嵌入式小尺寸屏幕产出「设计稿 → 资产 → 落地」三段交付物。核心纪律：**逻辑像素 1:1 对齐物理屏幕**；先定规范再画界面；图标动效资产由提取器工具生成，不手绘。

## 工作流

1. **设计稿** — 单文件 HTML，按「布局预算 → 色彩系统 → 组件规范」搭建，见阶段 1。
2. **资产提取器** — 复制 `assets/extractor-template.html`，替换产品自己的绘图函数与图标表，浏览器打开即可导出 PNG/GIF，见阶段 2。
3. **落地** — 按 `references/lvgl-implementation.md` 映射到 LVGL/EEZ。
4. **验证** — 全部完成后跑末尾「验证清单」。

## 阶段 1 — 设计稿规范

### 画布纪律
- 屏幕根节点逻辑尺寸 = 面板物理分辨率（如 320x240），内部定位/尺寸只用整数像素；预览放大用外层容器 `transform: scale(k)` 并保持内部逻辑像素不变，绝不放大逻辑尺寸。
- 每个组件用绝对定位 `(left, top, width, height)` 表达，并在 HTML 注释里标注坐标矩形 `(x, y, w×h)` — 落地 LVGL 时坐标直接照抄。
- 间距/圆角/字号用 CSS 变量做 token（如 --spacer-8/12/16/20、--radius-card），全稿复用，禁止随手写魔法数。

### 布局预算（先切区域，再排组件）
- 先把屏幕纵向切成功能带并固定 y 区间：状态栏（约 32px）/ 内容视口 / 页面指示点（约 6px 高，离底 4px）。
- 内容带内再横向切卡片（卡片宽度 = (屏宽 − 3×间距) / 2 之类），列出每个矩形的预算后再填内容，塞不下就先改预算而不是缩字号。
- 触摸目标 ≥ 40x40 逻辑像素；滑动翻页阈值经验值：位移 > 60px 或速度 > 0.45 px/ms；边缘回弹用位移除以 3 的橡皮筋。

### 色彩系统（深色底小屏）
- 层级四件套：背景 < 卡片 < 边框 < 文字，参考 bg #1B1E23 / card #262B33 / border #3A414C / text #FFFFFF / muted #9CA3AF。
- 语义强调色按含义全局唯一分配（温度暖黄、湿度冷青、成功绿、警示红……），每个强调色配一个 12~22% alpha 的同色柔光填充，用于图标内部填充与徽章底色。
- 小屏实测偏暗 — **色彩必须提亮**：主色选亮度 60~70% 的亮色（如 #FFCC4D、#5CE1FF、#FFD60A、#4ADE80），不要直接用 Material 400 系中间调。
- 描边可读性：48px 图标 2.6px、24px 图标 2.2px、20px 图标 2.0px，一律 round cap/join；小于 1.5px 的线在实机上会闪烁发虚。

### 组件模式（可复用套路）
- 传感器卡 144x102：左侧 3px accent 竖条 + 20px 图标 + 标题 + 右上徽章 + 30px 加粗大数值（tabular-nums）+ 11px 说明行。
- 状态栏 320x32：左侧加粗时间（tabular-nums）+ 日期，右侧信号格/电池。
- 天气/状态行卡 296x72：48px 动效图标 + 主文案 + 副文案 + 右侧同步胶囊。
- 底部指示点：6px 圆点，激活态拉长为 12px 胶囊并左移补位。
- 按压反馈：scale(0.94~0.985) + 背景提亮一档，120~150ms ease；入场动画 translateY(12px) + opacity，错峰 120ms。

## 阶段 2 — 资产提取器

模板 `assets/extractor-template.html` 已内置可用：纯 JS GIF89a 编码器（LZW、Netscape 无限循环、5-6-5 调色板量化防 256 色溢出）、SVG 转 PNG、单卡下载与一键顺序下载（180ms 间隔防浏览器拦截）。只需替换配色表、图标 SVG 表和 `drawFrame` 动画函数。

### SVG 几何纪律（血泪教训：温度计圆球被 viewBox 裁掉）
- 所有几何 + 半个描边必须落在 viewBox 内：`几何边界 + strokeWidth/2 ≤ viewBox`。SVG 默认 overflow hidden，超界笔画静默消失。
- 圆弧类图标（温度计圆球、水滴）参考公式：竖管终点 y = 圆心y − sqrt(r² − 半弦长²)，让弧线精确起于管壁。
- 每个图标写完用页面里 `path.getBBox()` 验证几何边界，加上描边半径后再与 viewBox 比较。
- 设计稿与提取器**必须共用同一条 path 字符串**，一处修两处同步，禁止各自维护。

### GIF 动效规范
- 透明背景 GIF 抗锯齿边缘会带杂边 — 优先用**卡片底色铺底**（disposal=1）；确需透明时 disposal=2 + alpha 阈值 80 去杂边。
- 帧数与体积：往复浮动 24~32 帧、delay 5~7cs（百帧级体积会撑爆闪存）。
- **旋转用对称性省帧**：8 重对称光芒只需生成转 45° 的帧（如 24 帧 x 4cs），播放等效 8 倍时长的 360° 旋转，体积 1/8 且极致丝滑。
- 多元素遮挡（多云/阴天）：前景云先 fill 卡片底色再 stroke，才能盖住后面的太阳/背景云；雨滴三滴相位差 1/3 周期，两端 25% 行程做透明度渐隐。

## 落地 LVGL/EEZ

见 `references/lvgl-implementation.md`：ManualTick 分层驱动（旋转/平移子控件替代整帧序列）、图片颜色格式选择、帧缓冲预算、EEZ Studio 对接与资产命名规范。

## 验证清单（交付前逐条跑）

1. 浏览器**不能直接打开 file://** — 在文档目录起 `python -m http.server <port>` 再走 http://localhost 验证；验证完停掉服务。
2. 控制台零报错；各类资源数量与预期一致（GIF/图层 PNG/图标各多少个）。
3. 截图对比设计稿：色彩提亮、线宽加粗、柔光填充是否生效；主题/背景选项切换往返一次确认无回归。
4. 图标几何：getBBox 边界 + 描边半径 ≤ viewBox（重点查圆弧收尾）。
5. 设计稿交互过一遍：滑动翻页、指示点点击、按压反馈、四态/多状态动效循环。
