# 嵌入式 C 语言编码与排版规范

## 1. 核心总则
1. **编码格式**：所有源文件（`.c`、`.h`、`.md`）与代码内文本/注释必须使用 **UTF-8** 编码，严禁混用 GB2312。
2. **作用域与修饰符**：非公开函数与静态变量必须加 `static` 修饰；只读指针/入参必须加 `const`。

## 2. 排版与语法风格 (严格执行)
### 2.1 缩进与控制结构
- **条件编译预处理缩进**：局部代码块内的 `#if`、`#ifdef`、`#endif` 等必须**随当前代码层级缩进**（严禁顶格）；`#endif` 必须附带条件注释。
```c
	#if(boardDCAC_EN)
	{KeyTriType_AcOnOffBuff, sizeof(...), KEY_MASK_NORMAL, v_act_dcac_short, "开关逆变"},
	#endif  //boardDCAC_EN
```
- **单行分支严禁大括号**：`if`、`else if`、`else` 单行语句**严禁添加 `{}`**，直接换行缩进书写。
```c
if (c_i2c_wait_ack(p_i2c_obj) < 0)
	return -1;
```

- **switch-case 分支语句块格式**：每个 case 分支语句块必须用大括号 `{}` 包裹其执行主体，`break;` 放置于大括号外独立一行。严禁省略 `{}`。
```c
case STI_INIT:
{
    tp_task->vp_func = v_sys_queue_task_init;
}
break;

default:
{
}
break;
```

### 2.2 结构体定义（1Tab -> 5Tab -> 5Tab 对齐，闭合无空格）
- `typedef struct` 与大括号顶格；**闭合大括号与类型名无空格**：`}SysInfo_T;`。
- **三列对齐规则**（严格遵循 `1Tab -> 5Tab -> 5Tab` 标尺）：
  1. **第 1 列（类型）**：行首缩进 **1Tab** 起始。
  2. **第 2 列（变量名）**：与类型列间隔 **5Tab** 宽度对齐。
  3. **第 3 列（注释）**：与变量名列间隔 **5Tab** 宽度对齐（第 **44** 列）。
- **块内一致**：同一结构体内的注释列必须统一（取该块所需的第 **44** 或 **48** 列）；若块内有成员需要更右（≥2 个 Tab），该块按逐行顺延，不做强制统一。
```c
typedef struct
{
	DevState_E    		eDevState;          //设备状态
	vu16				usVoltMax;			//0.01V
}SysInfo_T;
```

### 2.3 枚举定义（1Tab -> 5Tab 对齐，闭合无空格）
- `typedef enum` 与大括号顶格；**闭合大括号与类型名无空格**：`}SysPermObject_E;`。
- **双列对齐规则**（严格遵循 `1Tab -> 5Tab` 标尺）：
  1. **第 1 列（枚举常量名及赋值）**：行首缩进 **1Tab** 起始。
  2. **第 2 列（注释）**：与枚举常量列间隔 **5Tab** 宽度对齐（第 **24** 列）。
- **赋值书写**：`=` 两侧各留 **1 个空格**（`SPO_CHG = 0,`），**严禁用空格把 `=` 竖排拉齐**；常量名（含赋值）占满第 24 列时，注释顺延到下一个 Tab 位。
- **块内一致**：同一枚举内的注释列必须统一（取该块所需的第 **24** 或 **28** 列）；若块内有项需要更右（≥2 个 Tab），该块按逐行顺延，不做强制统一。
```c
typedef enum
{
	SPO_CHG = 0,		//充电
	SPO_ALL,			//充放电
}SysPermObject_E;
```

### 2.4 宏定义 #define 排版（4Tab -> 10Tab -> 2Tab 对齐）
- `#define` 顶格书写；列位置为准，列间距用 **Tab** 补齐（已合规的行不必改写）。
- **宏名称**：与 `#define` 间隔 **4Tab** 宽度对齐（第 **16** 列）。
- **宏取值**：与宏名称间隔 **10Tab** 宽度对齐（第 **56** 列）。
- **行尾注释**：与宏取值间隔 **2Tab** 宽度对齐（第 **64** 列）；宏取值过长越过第 64 列时，注释顺延到下一个 Tab 位。
- **无值宏**（头文件保护等）：保持 `#define XXX_H` 原样书写，不右移到第 16 列。
- **函数式宏**（带参数）：`NAME(params)` 作为**一个整体**从第 **16** 列起写，**参数表内部不参与列对齐**（保持 `NAME(a, b)` 原样、逗号后一个空格，严禁用 Tab 把参数撑开），宏取值仍对齐第 **56** 列。
```c
#define			boardWDGT_EN							1		/* 看门狗使能 */
#define			RANGE(val, min, max)					(((val) < (min)) ? false : (((val) > (max)) ? false : true))
```
> **禁改例外**：被外部工具解析的宏行必须保留原有**空格**分隔，不得改成 Tab 缩进，否则解析失效：
> - Keil `Configuration Wizard` 文件（含 `<<< Use Configuration Wizard in Context Menu >>>`），如 `BOOT\Application\board_config.h`（文件内已注明"此处缩进不可以用Tab"）；
> - 被 `APP\MergeTool.bat` 以 `for /f "tokens=3 delims= "` 读取的宏：`boardSOFTWARE_VERSION`、`flashBOOT_STACK_SIZE`。

## 3. 命名规范速查表
### 3.1 函数命名
| 类型 | 格式 | 示例 | 规则说明 |
| :--- | :--- | :--- | :--- |
| **全局函数** | `返回类型(小写) + 模块名(大驼峰/全大写) + _ + 动宾(大驼峰)` | `void vBMS_SendData(uint8_t uc_data);` | 外部链接，大驼峰 |
| **局部函数** | `static + 返回类型(小写) + _ + 动宾(小写下划线)` | `static void v_send_data(uint8_t uc_data);` | 仅内部使用，必须加 `static` |
- **参数顺序与格式**：输入参数 -> 修改参数 -> 输出参数。单词全小写下划线（如 `const uint8_t *p_src, uint8_t *p_dst`）。
- **返回值前缀**（按返回类型取，工程通用缩写）：
  `v`(void)、`b`(bool/BaseType_t)、`t`(结构体)、`e`(枚举)、`u`(联合)、`pv`(void*)、`p`(其它指针)、`c`(s8/int8_t)、`uc`(u8/uint8_t)、`s`(s16)、`us`(u16/uint16_t)、`l`(s32)、`ul`(u32/uint32_t)、`f`(float)、`d`(double)、`u64` / `ull`(64 位无符号，二者均可)。
  > `uint32_t`/`u32` **统一用 `ul`**（原 `ui` 前缀已废弃，不再作为合规前缀）。
  > 新增类型缩写时，按"类型名首字母/工程惯用缩写"小写即可，不必回改已有函数。

### 3.2 变量与指针命名
| 类别 | 前缀 | 命名法 | 示例 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| **全局变量** | `G_` + 类型前缀 | 大驼峰 (PascalCase) | `uint8_t G_ucNum;` | 跨文件全局使用 |
| **静态全局** | `S_` 或 `s_` + 类型前缀 | 大驼峰 (PascalCase) | `static uint8_t S_ucNum;` | 文件内静态全局 |
| **普通局部** | 类型前缀 | 全小写下划线 (snake_case) | `uint8_t uc_num;` | 函数局部变量 |
| **静态局部** | `s_` + 类型前缀 | 全小写下划线 (snake_case) | `static uint8_t s_uc_num;` | 函数内静态局部 |
| **全局指针** | `P_` | 大驼峰，`*` 紧挨变量名 | `uint8_t *P_MsgAddr;` | 跨文件全局指针 |
| **局部指针** | `p_` | 全小写下划线，`*` 紧挨变量名 | `uint8_t *p_msg;` | 局部指针 |

### 3.3 自定义类型与常量命名
| 类别 | 前缀/后缀 | 命名法 | 示例 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| **结构体类型** | `_T` 后缀 | 大驼峰 | `BAT_T` | 成员带类型前缀，三列 Tab 对齐 |
| **结构体变量** | `t` 前缀 | 大驼峰 | `BAT_T tBAT;` | 若文件名即结构体名可省前缀 |
| **枚举类型** | `_E` 后缀 | 大驼峰 | `WorkState_E` | 枚举值全大写下划线，双列 Tab 对齐 |
| **枚举变量** | `e` 前缀 | 大驼峰 | `WorkState_E eWorkState;` | |
| **联合类型** | `_U` 后缀 | 大驼峰 | `InitFinish_U` | |
| **联合变量** | `u` 前缀 | 大驼峰 | `InitFinish_U uInit;` | |
| **宏/常量** | 模块小写前缀 | 全大写下划线 | `#define portMAX_DELAY 0xFFFF`<br>`const double PI_ROUNDED = 3.14;` | 纯常量全大写，带模块小写前缀，按列对齐 |

- **类型后缀统一 `_T` / `_E` / `_U`**：历史遗留的 Linux 风格小写 `_t`（如 `UpdateFrame_t`）**允许存量保留不强制改**，但**新增类型一律禁止**用 `_t`。
- **前缀优先级（存储期 vs 类型）**：文件作用域的**结构体/枚举/联合变量一律用类型前缀**（`t` / `e` / `u` + 大驼峰，如 `tAppParam`、`eWorkState`、`uInit`），**不再叠加 `G_`/`S_`/`s_`**；`G_` / `S_` / `s_` 只用于文件作用域的**基本类型与指针**变量。
- 结构体/枚举/联合**成员**同样沿用 `t` / `e` / `u` 类型前缀。
