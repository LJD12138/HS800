# LVGL / EEZ 落地映射

设计稿与提取器产出的资产如何落到 LVGL（v8/v9）与 EEZ Studio。保持三方（设计稿 / 提取器 / 代码）同一套坐标与命名。

## 资产颜色格式

| 资产类型 | 格式 | 说明 |
|---|---|---|
| 不透明整屏背景/照片 | RGB565 | 与帧缓冲同格式，blit 零转换 |
| 卡片底色铺底的 GIF | RGB565 帧序列 | 铺底色 = 卡片色，运行时无 alpha 混合 |
| 透明图标 / 拆解图层 PNG | ARGB8888（或 A8 + 单色） | 确认 `LV_COLOR_DEPTH=16`，透明图走 `lv_img_dsc` 含 alpha 通道 |
| 纯色小图标 | A8 字体位图思路 | 单色图标可转 A8 省内存，用 `lv_img_set_style_img_recolor` 换色 |

## 分层拆解（ManualTick 模式，首选）

多元素动效不要整帧序列化（几十帧 GIF 吃闪存），拆成静态图层 PNG + 代码驱动：

- **晴** = 太阳圆心层（不动）+ 旋转光芒层 → `lv_img_set_angle(rays, angle)` 每 tick 递增；8 重对称光芒 angle 只需在 0~450（0.1° 单位，即 45°）内循环，视觉等效 360° 无缝旋转。
- **多云** = 小太阳层 + 前景云层 → 两层分别 `lv_img_set_offset_x/y` 或 `lv_obj_set_x/y` 做相位相反的往复（太阳 (+2,-2)、云 (-1.5,+1)，正弦 4s）。
- **阴** = 后景云层（+1.5,0）+ 前景云层（-2,0），5s 往复；前景云 PNG 自带卡片底色填充才能盖住后景。
- **雨** = 雨云层（静止）+ 3 根雨滴层，相位差 1/3 周期：y 从 -2 到 +4 平移，行程前后 25% 用 `lv_obj_set_style_opa` 渐隐。
- 动画驱动用 16~33ms 周期的 `lv_timer` 或 `lv_anim`；**切页/拖动时暂停**所有动画 timer，回页再恢复，避免撕裂与无谓功耗。

## 帧缓冲与性能预算

- 全屏 320x240x2B = 150KB；双缓冲 x2 = 300KB — 先确认 PSRAM/SRAM 预算再谈动画。
- 动画只 invalidate 局部区域（脏矩形），别整屏重绘。
- 柔光、渐变、抗锯齿在提取器里预合成进资产，运行时只做 1:1 blit；避免运行时大图 alpha 混合与实时旋转缩放。
- `lv_img_set_angle` 是软件变换，48x48 以内可接受；更大的旋转对象改用预生成帧序列。

## EEZ Studio 对接

- 用 Image Widget 承接提取器导出的 PNG，坐标直接抄设计稿注释里的 `(x, y, w×h)`，单位逻辑像素 1:1。
- 屏幕骨架（导航栏/页面容器/指示点）在 Studio 里搭；动画既可绑 Studio 事件，也可生成代码后手写 tick 函数。
- 字体：数值/时间用 tabular 数字字体防抖动；字号 11/12/13/15/17/30 与设计稿一致，别用默认主题字号。

## 资产命名规范

`<类别>_<状态>_<宽x高>.<ext>`，与提取器输出文件名严格一致：

- `icon_temp_20x20.png` / `icon_humi_20x20.png` — 传感器图标
- `weather_sunny_48x48.gif` 等 — 整帧动效（仿真/预览用）
- `layer_sunny_core_48x48.png` / `layer_sunny_rays_48x48.png` 等 — 实机分层驱动用
- `app_<id>_24x24.png`（裸图标）/ `app_<id>_box_48x48.png`（带底座）— 应用网格
